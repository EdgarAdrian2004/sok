Cómo recorrerlo

Abre index.html directamente en el navegador. Usa Tab para moverte, Ctrl + K para buscar una sección y ? para ver los atajos.

Temas

El tema oscuro es el predeterminado, igual que en Figma. El botón de la cabecera alterna a claro y la elección se conserva entre pantallas.

Datos de ejemplo

Los valores de CPU, memoria y respaldos son ficticios. El prototipo valida jerarquía, estados y accesibilidad; no ejecuta acciones reales sobre Windows.
